## 🛠️ Architecture & Technologies du site

* **Front-end statique :** HTML5, CSS3 ([`css/style.css`](css/style.css)) et JavaScript Vanilla ([`js/main.js`](js/main.js)).
* **Icônes :** Font Awesome 6.4.0.
* **Fonctionnalités :**
  * Filtrage interactif des projets par balises (`data-category`).
  * Animations progressives au défilement (`IntersectionObserver`).
  * Lecteur PDF embarqué et bouton de téléchargement pour le CV.
  * Mise en page responsive (ordinateur, tablette, mobile).
